The Pastiche popup: a searchable list of recent clipboard entries, text and images, navigated with the arrow keys.

Features

⌘

Shortcut

⌘' opens the popup. Change it in Settings.

↕

Keyboard

Arrows move, Return pastes, ⌘1–⌘0 jump to a row.

▣

Text and images

Images show as large previews. Filter by type with ←→.

⌕

Search

Start typing to filter. Every word must match.

↩

Paste

Returns focus to your app and presses ⌘V. Needs the Accessibility permission.

✕

History

Saved to disk, 500 items by default. Delete an entry with ⌫.

Paste and delete keys are configurable. ⌫ deletes only outside the search field; ⌘⌫ works everywhere.

Privacy

  • Local only. The source has no networking code. This finds nothing:grep -rnE "URLSession|NWConnection" Sources
  • Secrets skipped. Items an app marks as concealed, transient or auto-generated are not recorded.
  • Ignored apps. Copies from listed apps are dropped. 1Password, Bitwarden and Keychain Access are pre-filled.
  • Not encrypted. History is plain JSON and PNG files in ~/Library/Application Support/Pastiche.
  • Accessibility is optional. It is only used to send ⌘V.

Install

Requires macOS 14 or later. Releases are signed, notarized and universal.

Homebrew

brew tap bcollard/pastiche
brew trust --tap bcollard/pastiche
brew install --cask pastiche

Update with brew upgrade --cask pastiche. Homebrew 6 and later asks you to trust third-party taps.

Download

Get the zip from the releases page and move Pastiche.app to Applications.

From source

git clone https://github.com/bcollard/pastiche.git
cd pastiche && make install

Needs the Xcode command-line tools. A local build targets your Mac's architecture.

  1. Find the clipboard icon in the menu bar. There is no Dock icon.
  2. Copy something, then press ⌘ '.
  3. Grant Accessibility when asked. It is optional: without it you paste with ⌘V yourself.

FAQ

Why does it ask for Accessibility?

To press ⌘V in the app you came from. Without it, Pastiche copies the item and you paste it yourself.

Does it record passwords?

Not from apps that mark them as concealed; 1Password does. Add any other app to the ignored list in Settings, or delete the entry with ⌫.

Where is my history?

In ~/Library/Application Support/Pastiche/. It is not encrypted.

Is formatting kept?

No. Pastiche stores plain text and images.

Can I change the shortcut?

Yes, in Settings. The paste key, the delete key and the history size (10 to 10,000) are configurable too.

Does it sync between Macs?

No.

Does it run on Intel Macs?

Releases are universal. A local build targets the Mac it was built on.
