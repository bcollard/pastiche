**Description** (4000):

Pastiche is an open-source clipboard manager for macOS. Press a shortcut, pick something you copied earlier, press Return to paste it.

WHAT IT DOES
• Free and open source: MIT licensed, source code at github.com/bcollard/pastiche
• Keeps a history of what you copy: text and images
• Opens on a global shortcut, ⌘' by default
• Move with the arrow keys, paste with Return
• Filter by type: All, Text or Images
• Search as you type
• Pastes into the app you came from, or only copies the item
• A pasted item moves to the top of the list
• Delete an entry with Backspace

KEYBOARD
↑ ↓ move · ← → switch type · Tab search · Return paste · ⌘1 to ⌘0 paste a numbered row · ⌫ delete · Esc close

PRIVACY
• Nothing leaves your Mac. Pastiche has no network access and no analytics.
• Items an app marks as concealed, transient or auto-generated are never recorded.
• Ignore any app: copies made while a listed app is in front are dropped.
• History is stored on your Mac and is not encrypted.

PERMISSIONS
Pasting into another app needs the Accessibility permission. It is the only permission Pastiche asks for. Without it, Pastiche still copies the selected item and you paste it yourself with ⌘V.

REQUIREMENTS
macOS 14 or later. Pastiche runs in the menu bar and has no Dock icon.

**What's New** (4000), first release:
First release on the Mac App Store. Text and image history, search, type filter, keyboard navigation, and pasted items move to the top of the list.

## App Review

**Review notes** (4000):

Pastiche is a menu bar app. It has no Dock icon and no main window.

To test:
1. Launch Pastiche. A clipboard icon appears in the menu bar.
2. Copy some text and an image in any app.
3. Press ⌘' to open the popup. Select an item with the arrow keys and press Return.

Pasting into another app: Pastiche sends ⌘V to the app you came from, which macOS only allows with the Accessibility permission. Enable it in System Settings > Privacy & Security > Accessibility: click +, choose Pastiche, and switch it on. It is the only permission requested and it is optional. Without it, the app copies the selected item to the clipboard.

The app has no account, no in-app purchase, no network access and no analytics. Clipboard content stays on the device. Privacy policy: https://pastiche.runlocal.dev/privacy.html
